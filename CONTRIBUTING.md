# Contributing

Thanks for helping improve PS5 Shell. The project is experimental and targets Linux Wayland sessions using labwc. The installed GDM session remains named **Console DE** for compatibility with existing configuration and launch commands.

## Issues

Before opening an issue, check the troubleshooting guide and run `console-de-doctor` if the problem is related to installation, graphics, audio, or controller input. Include:

- Distribution and release.
- Whether the session is on bare metal or a virtual machine.
- Display resolution and, for a VM, whether 3D acceleration is enabled.
- Controller model and connection type when relevant.
- Reproduction steps and the relevant log excerpt.

Remove account details, access tokens, unrelated logs, and personal paths before posting.

## Changes

- Keep changes focused and explain the user-visible effect.
- Preserve the current controller-first navigation and session behavior unless a change explicitly targets them.
- Do not add third-party assets unless their redistribution terms are clear.
- Do not include Steam credentials, personal library data, screenshots containing private information, or user cache files.
- Update the relevant documentation when controls, dependencies, or installation behavior changes.
